# Security and privacy

Do not post credentials, tokens, account details, addresses, private logs, or exploitable vulnerability details in public issues or discussions.

For an integration concern, provide only a minimal redacted description. If it involves a security vulnerability, use the repository's private vulnerability reporting feature if available. If unavailable, ask the maintainer for a private reporting channel without disclosing exploit details publicly.

This repository contains documentation and client examples, not the private application or model. The examples are provided without warranty; keep device safety interlocks and explicit limits in any automation.
